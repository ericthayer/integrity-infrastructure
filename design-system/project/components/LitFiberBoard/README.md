# LitFiberBoard

Brand-kit board for the Lit Fiber concept: nine panels from the logo to system details, painted by `data-theme="lit-fiber"`.

Lit Fiber: dark glass and light in motion. The client's chosen concept; the website is built in it.

## Panels
Logo on surface (reversed, over the page veil), construction (the two-enclosure panel and the pill), digital (the island header and the scene hero rendered at 1280px, with the strand scene live when three.js loads), brand essence, color with contrast, type (Montserrat 500 with Michroma labels), the mark in the field, image direction (night work, cool grade) and system details (pills with the orb, a field, tags, 1.25 stroke icons).

## Use
Presentation only: concept reviews with the client. The board forces its own theme, so it looks the same whichever theme the page is in. Nothing here ships on the site.

## Avoid
Adding panels with invented content: every panel shows real assets, real tokens or real components.
