# Tag

A small metadata label: location, trade, job type. One accent tag per view at most.

## Use
- `span.ii-tag`, optionally with a leading icon; `ii-tag--accent` (ink on orange) for the single highlight such as "Now hiring". Group in `ul.ii-tag-list`.

## Consumer provides
The label and, optionally, an icon.

## WordPress
A text element with the class.

## Avoid
Tags overlaid on photos, decorative status dots, and more than one accent tag in view.
