# FAQ

Questions and answers as native `details` elements, one open at a time, with the heading sticky beside them on desktop.

## Use
- `div.ii-faq` of `details.ii-faq__item[name="faq"]` with `summary.ii-faq__q` and `div.ii-faq__a`. Wrap with `ii-faq-layout` for the two-column layout.
- Answers come from the live site where they exist (industries served, maintenance and emergency repair). Home and Services also answer the scope question: we build up to residential locations, and the internet provider handles installation inside the home.

## Consumer provides
Question and answer pairs; three to six per page.

## WordPress
A repeater or FAQ post type; output native details (no JavaScript accordion). Add FAQPage structured data.

## Avoid
Marketing copy disguised as questions, and more than six items.
