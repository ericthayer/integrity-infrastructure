# Notice

A short message with an icon and a title: info, success or danger. Status is never shown by color alone.

## Use
- `div.ii-notice.ii-notice--info|success|danger` with an icon and `ii-notice__body` (title + sentence + optional link).
- Uses: the emergency repair line on Contact, form feedback, the job feed fallback.

## Consumer provides
Tone, title, sentence, optional link.

## WordPress
A reusable block with a tone property.

## Avoid
Stacking several notices, and toasts for anything a person must act on.
