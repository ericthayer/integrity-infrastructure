# WorkLightBoard

Brand-kit board for the Work Light concept: nine panels from the logo to system details, painted by `data-theme="work-light"`.

Work Light: dark, cinematic, orange as the light on the job site, all-sharp with the stencil notch.

## Panels
Logo on surface, construction, digital (a real header and hero rendered at 1280px and zoomed to fit), brand essence, color with contrast, type, the mark in the field (crops of the real truck door or shirt), image direction, and system details (buttons, a field, tags, service icons).

## Use
Presentation only, and archived: Work Light was an exploration; the client chose Lit Fiber. The board forces its own theme, so it looks the same whichever theme the page is in. Nothing here ships on the site.

## Avoid
Adding panels with invented content: every panel shows real assets, real tokens or real components.
