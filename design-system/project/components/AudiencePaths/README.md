# AudiencePaths

Three next steps for three audiences: hire us, join the crew, partner with us. One feature path with a photo, two stacked.

## Use
- `ul.ii-paths` with `li.ii-path.ii-path--feature` first (photo + body), then two `li.ii-path`. The arrow link is stretched so the whole card is clickable.
- Labels: Request a quote, View open roles, Start an inquiry.

## Consumer provides
Title, one sentence and link per path; a photo for the feature path.

## Oxygen
A Component with three slots.

## Avoid
Three equal cards, and paths that duplicate the header nav without adding context.
