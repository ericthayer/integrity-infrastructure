# SubcontractorForm

The subcontractor inquiry: company and contact, trades, crew size, service area, certificate of insurance and EMR.

## Use
- Lives on the Subcontractor Inquiry page; submit label "Start an inquiry". File upload accepts PDF or images, 10 MB max, and shows the chosen file name in the hint.
- Required: company, contact, email, phone, at least one trade, crew size, service area. COI, EMR and notes are optional.

## Consumer provides
The form action, the review owner, insurance minimums (shown on the page above the form).

## Oxygen
Build in the chosen form plugin with file uploads stored privately.

## Avoid
Asking for documents the team will not review, and public file URLs for uploads.
