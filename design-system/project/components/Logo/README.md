# Logo

The Integrity Infrastructure lockup, used exactly as supplied: full color on light grounds, reversed on dark grounds and photography.

## Use
- Full color (`integrity-infrastructure-logo.png`) on `surface` in As-Built and Crew; reversed (`integrity-infrastructure-logo-reversed.png`, provisional) in Work Light and over photos.
- In the header, render both files as `img.ii-logo.ii-logo--for-light` and `img.ii-logo.ii-logo--for-dark`; the concept's `--logo-on-light` / `--logo-on-dark` shows the right one, and the overlay header switches to the reversed file automatically.
- Clear space equals the flame's width. Header height 44px mobile, 52px desktop; the two small lines of the lockup are not legible there, so the wordmark carries recognition.

## Consumer provides
The link target (home) and alt text "Integrity Infrastructure home" on the header link's image; decorative repeats use `alt=""`.

## Oxygen
Image element with the two classes above, or an SVG once the client supplies vectors.

## Avoid
Redrawing, re-typesetting, stretching, outlines, shadows, or recoloring beyond the two supplied files. Placing the full-color file on dark grounds.
