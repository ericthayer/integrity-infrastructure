# CTABand

The closing band on every page: a short invitation, the primary quote button and the phone number side by side.

## Use
- `section.ii-cta-band` containing `ii-cta-band__inner` with `ii-cta-band__copy` and `ii-cta-band__actions`.
- Heading "Let's work together" (the live site's own line), one sentence, Request a quote, and CallLink.

## Consumer provides
Heading, sentence, quote link, phone.

## Oxygen
A reusable Component placed above the footer.

## Avoid
A second primary action, and "Get a quote" wording (the label is Request a quote).
