# LeaderCard

Leadership portraits with name and title for the About page, in a responsive grid.

## Use
- `ul.ii-leaders` of `li.ii-leader`: portrait in `ii-media` (4:5) or a PhotoSlot until supplied, `ii-leader__name`, `ii-leader__role`, optional one-line bio.

## Consumer provides
Names, titles, portraits and short bios, approved by each person.

## Oxygen
A Team post type or repeater.

## Avoid
Placeholder names, stock portraits, and avatar icons.
